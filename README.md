## about the certification

CRTP is a hands-on certification focused on **attacking and defending Active Directory environments**. It is assessed through a practical lab exam rather than multiple-choice questions, so it tests whether you can actually enumerate, escalate, and move through a Windows domain environment.

---

## skills demonstrated

```bash
ibrahim@htu:~$ ls skills_demonstrated/
```

- **Active Directory enumeration:** users, groups, computers, GPOs, OUs, ACLs, and trusts
- **Local privilege escalation:** Windows misconfigurations and service abuse
- **Domain privilege escalation:** abusing misconfigurations, delegation, and group memberships
- **Kerberos attacks:** Kerberoasting, AS-REP roasting, and ticket-based attacks
- **Credential abuse:** lateral movement, pass-the-hash, and pass-the-ticket
- **Persistence:** golden ticket, silver ticket, and DCSync concepts
- **Trust abuse:** cross-domain and cross-forest escalation
- **Defense awareness:** detection approaches and mitigations for each attack class

---

## exam approach

```bash
ibrahim@htu:~$ cat methodology.txt

[1] enumerate     -> map the domain, users, groups, trusts, ACLs
[2] foothold      -> gain initial access and escalate locally
[3] escalate      -> move toward domain-level privileges
[4] lateral move  -> pivot across machines and domains
[5] persist       -> demonstrate impact and persistence
[6] report        -> document every step clearly and reproducibly
```
